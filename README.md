## 快速开始

```bash
git lfs install
git clone https://github.com/zhaojinting2020/kb-deep-learning-ai.git
cd kb-deep-learning-ai
```

用 Obsidian 打开本仓库根目录作为 vault；启动页即本文件。书签索引见 [MOC-dl-ai](content/00-导航/MOC-dl-ai.md)。
