# 深度学习与AI

深度学习与 AI 学习笔记（Obsidian vault + [Quartz](https://quartz.jzhao.xyz) 站点）。

在线阅读：https://zhaojinting2020.github.io/kb-deep-learning-ai/


## 快速开始

```bash
git lfs install
git clone https://github.com/zhaojinting2020/kb-deep-learning-ai.git
cd kb-deep-learning-ai
```

用 Obsidian 打开 `content/` 作为 vault，从 [`content/index.md`](content/index.md) 进入。

本地预览站点：

```bash
npm ci
npx quartz build --serve
```
