# 深度学习与AI

深度学习与 AI 学习笔记（Obsidian vault）。

仓库：https://github.com/zhaojinting2020/kb-deep-learning-ai

## 写作与同步（飞书为主）

1. 在飞书写 / 改
2. Cursor 拉取到本仓 `content/`
3. Obsidian 打开 `content/` 审阅
4. `git push`

## 快速开始

```bash
git lfs install
git clone https://github.com/zhaojinting2020/kb-deep-learning-ai.git
cd kb-deep-learning-ai
```

用 Obsidian 打开 `content/` 作为 vault，从 [`content/index.md`](content/index.md) 进入。
