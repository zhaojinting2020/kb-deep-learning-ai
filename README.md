# 深度学习与AI

深度学习与 AI 学习笔记（从 bookmarks-kb 拆出）

拆分自私有知识库 [bookmarks-kb](https://github.com/zhaojinting2020/bookmarks-kb)。

## 怎么用

1. `git clone` 本仓库
2. 用 Obsidian 打开仓库根目录作为 vault
3. 入口：`Home.md` → `index/MOC-*.md` → `content/深度学习与AI/`

## 目录

| 路径 | 用途 |
|------|------|
| `content/深度学习与AI/` | 笔记正文 |
| `attachments/` | 笔记引用的 PDF / 图片（子集） |
| `index/` | MOC |
| `Home.md` | 入口 |

## 与总仓关系

- 流水线脚本（书签 crawl、飞书 pull、PDF import）仍在 `bookmarks-kb`
- 本仓面向阅读与专题整理；附件未全量同步时，可对照总仓或百度网盘 `attachments/`
