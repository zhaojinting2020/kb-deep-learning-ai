# 交叉熵损失

在统计学与深度学习中，损失函数衡量预测与真实值的偏差。设真实输出为 \(y\)，预测为 \(a\)，训练目标就是让 \(|a - y| \to 0\)，即最小化损失。分类任务里，**交叉熵**通常优于**均方误差（MSE）**：配合 sigmoid / softmax 时梯度性质更好，收敛更快。James McCaffrey 对此有专门讨论：[Why you should use cross-entropy error instead of classification error or mean squared error](https://jamesmccaffrey.wordpress.com/2013/11/05/why-you-should-use-cross-entropy-error-instead-of-classification-error-or-mean-squared-error-for-neural-network-classifier-training/)。

## 均方误差（MSE）

二分类场景下，预测经 sigmoid 映射到 \((0,1)\)：

\[
\text{loss} = \frac{(a - y)^2}{2}
\]

sigmoid：

\[
\sigma(x) = \frac{1}{1 + e^{-x}}
\]

MSE 能表达回归误差，但在分类问题上，当预测接近 0/1 时 sigmoid 饱和，梯度变小，训练变慢。

## 交叉熵

对真实分布 \(p\) 与预测分布 \(q\)，交叉熵：

\[
H(p, q) = -\sum_i p(i) \log q(i)
\]

分类中 \(p\) 常为 one-hot（真实类为 1，其余为 0），\(q\) 为模型 softmax/sigmoid 输出。

### 二分类

\[
L = -\big[y \log(a) + (1-y)\log(1-a)\big]
\]

### 多分类

\[
L = -\sum_i y_i \log(a_i)
\]

交叉熵直接惩罚"给正确类分配的概率过低"，与分类目标一致；配合 log-softmax 数值更稳定。

## 为何优于 MSE（分类）

- MSE 对所有维度平等惩罚，不强调"正确类概率应接近 1"
- sigmoid + MSE 在预测错误且置信度高时梯度仍可能很小
- 交叉熵对数项在预测与标签差距大时梯度更大，利于快速修正

## TensorFlow 四种常用交叉熵

输入 **`logits`**（未做 sigmoid/softmax 的原始输出），函数内部再做激活并算损失；**不要**先手动 sigmoid/softmax 再传入。

| 函数 | 用途 |
|------|------|
| `tf.nn.sigmoid_cross_entropy_with_logits` | 二分类 / 多标签 |
| `tf.nn.softmax_cross_entropy_with_logits` | 多分类（标签 one-hot） |
| `tf.nn.sparse_softmax_cross_entropy_with_logits` | 多分类（标签为类别索引） |
| `tf.nn.weighted_cross_entropy_with_logits` | 带类别权重的 sigmoid 交叉熵 |

`sigmoid_cross_entropy_with_logits` 对 batch 中每个样本返回逐元素 loss，形状 `[batch_size, num_classes]`，一般配合 `tf.reduce_mean` 使用。

## Keras / PyTorch 对应

- **Keras** `binary_crossentropy`：等价于 sigmoid + 二分类交叉熵；若用 `from_logits=True` 则直接吃 logits
- **PyTorch** `F.binary_cross_entropy_with_logits`：内部含 sigmoid，无需手动激活
- **PyTorch** `nn.CrossEntropyLoss`：内部含 log-softmax + NLL，输入 logits 与类别索引

对比：

```python
# PyTorch 二分类 — 需手动 sigmoid
loss = F.binary_cross_entropy(torch.sigmoid(input), target)

# 推荐：with_logits
loss = F.binary_cross_entropy_with_logits(input, target)
```
